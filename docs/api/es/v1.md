# Referencia de la API: `/v1/chat`, `/v1/models`

Idioma: [English](../en/v1.md) | **Español** · [Índice de la API](README.md)

### `POST /v1/chat/completions`

Función: `spike/server/openai_api.py` → `chat_completions`

**Cuerpo** (`application/json`)

| Campo | Tipo | Obligatorio | Por defecto | Descripción |
|---|---|---|---|---|
| `model` | string | sí |  | `spike-auto`, `spike-<especialista>` o `<proveedor>/<modelo>` (ver `GET /v1/models`) |
| `messages` | object[] | sí |  | `role` (`system`, `user`, `assistant`, `tool`) y `content` (texto) |
| `stream` | boolean |  |  | responder como eventos SSE |
| `stream_options.include_usage` | boolean |  |  | añadir el uso de tokens al final del stream |
| `tools` | object[] |  |  | herramientas de función del cliente; las llamadas vuelven al cliente |
| `tool_choice` | string |  |  | `none` descarta las herramientas |
| `response_format` | object |  |  | `{"type": "json_object"}` o `json_schema` con un `schema` |
| `temperature` | number |  |  |  |
| `top_p` | number |  |  |  |
| `max_tokens` | integer |  |  | también `max_completion_tokens` |
| `stop` | string \| string[] |  |  |  |
| `n` | integer |  |  | solo se admite 1 |

**Respuesta**: `200`

**Errores**

| Código | Mensaje |
|---|---|
| `400` | 'messages' must be a non-empty list; 'model' is required; 'tools' must be a list; '{…}' must be a number; (mensaje construido al ejecutar); image input is not supported yet; message content must be a string or a list of parts; n &gt; 1 is not supported; only function tools are supported; the last message must come from the user or be a tool result; the request body must be JSON; the request body must be a JSON object; tool call arguments must be a JSON object; unsupported content part type '{…}'; unsupported message role '{…}'; unsupported response_format type '{…}' |
| `401` | invalid or missing API key: send 'Authorization: Bearer &lt;SPIKE_API_TOKEN&gt;' |
| `403` | browser requests need an API token: start SPIKE with SPIKE_API_TOKEN set; without SPIKE_API_TOKEN only programs on this computer can use the API |
| `404` | unknown model '{…}': GET /v1/models lists the available ones |
| `500` | {…}: {…} |
| `502` | (mensaje construido al ejecutar) |

**Ejemplo**

```bash
curl -s -X POST 'http://127.0.0.1:8740/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -d '{"model": "spike-auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

### `GET /v1/models`

Función: `spike/server/openai_api.py` → `models`

**Respuesta**: `200`

**Errores**

| Código | Mensaje |
|---|---|
| `401` | invalid or missing API key: send 'Authorization: Bearer &lt;SPIKE_API_TOKEN&gt;' |
| `403` | browser requests need an API token: start SPIKE with SPIKE_API_TOKEN set; without SPIKE_API_TOKEN only programs on this computer can use the API |

**Ejemplo**

```bash
curl -s 'http://127.0.0.1:8740/v1/models'
```
