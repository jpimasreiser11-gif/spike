# API reference: `/v1/chat`, `/v1/models`

Language: [Español](../es/v1.md) | **English** · [API index](README.md)

### `POST /v1/chat/completions`

Handler: `spike/server/openai_api.py` → `chat_completions`

**Body** (`application/json`)

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `model` | string | yes |  | `spike-auto`, `spike-<specialist>` or `<provider>/<model>` (see `GET /v1/models`) |
| `messages` | object[] | yes |  | `role` (`system`, `user`, `assistant`, `tool`) and `content` (text) |
| `stream` | boolean |  |  | answer as server-sent events |
| `stream_options.include_usage` | boolean |  |  | add a usage chunk at the end of a stream |
| `tools` | object[] |  |  | function tools of the client; the model's calls go back to the client |
| `tool_choice` | string |  |  | `none` drops the tools |
| `response_format` | object |  |  | `{"type": "json_object"}` or `json_schema` with a `schema` |
| `temperature` | number |  |  |  |
| `top_p` | number |  |  |  |
| `max_tokens` | integer |  |  | also `max_completion_tokens` |
| `stop` | string \| string[] |  |  |  |
| `n` | integer |  |  | only 1 is supported |

**Response**: `200`

**Errors**

| Code | Message |
|---|---|
| `400` | 'messages' must be a non-empty list; 'model' is required; 'tools' must be a list; '{…}' must be a number; (message built at run time); image input is not supported yet; message content must be a string or a list of parts; n &gt; 1 is not supported; only function tools are supported; the last message must come from the user or be a tool result; the request body must be JSON; the request body must be a JSON object; tool call arguments must be a JSON object; unsupported content part type '{…}'; unsupported message role '{…}'; unsupported response_format type '{…}' |
| `401` | invalid or missing API key: send 'Authorization: Bearer &lt;SPIKE_API_TOKEN&gt;' |
| `403` | browser requests need an API token: start SPIKE with SPIKE_API_TOKEN set; without SPIKE_API_TOKEN only programs on this computer can use the API |
| `404` | unknown model '{…}': GET /v1/models lists the available ones |
| `500` | {…}: {…} |
| `502` | (message built at run time) |

**Example**

```bash
curl -s -X POST 'http://127.0.0.1:8740/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -d '{"model": "spike-auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

### `GET /v1/models`

Handler: `spike/server/openai_api.py` → `models`

**Response**: `200`

**Errors**

| Code | Message |
|---|---|
| `401` | invalid or missing API key: send 'Authorization: Bearer &lt;SPIKE_API_TOKEN&gt;' |
| `403` | browser requests need an API token: start SPIKE with SPIKE_API_TOKEN set; without SPIKE_API_TOKEN only programs on this computer can use the API |

**Example**

```bash
curl -s 'http://127.0.0.1:8740/v1/models'
```
