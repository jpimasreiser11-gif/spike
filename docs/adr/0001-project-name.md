# ADR 0001 — Nombre público Spike

- Estado: **Aceptada por Joan** (instrucción explícita, 2026-10-16).
- Decisión: proyecto **Spike**, modelos `Spike <especialidad>`, por ejemplo `Spike Finance`.
- Alcance: etiquetas de interfaz, documentación y modelos futuros; las rutas `nexus-*` en el plan son nombres heredados y requerirán decisión explícita al incorporar el `PLAN.md` íntegro.
- Consecuencia: el nombre comercial definitivo no supone derechos sobre marcas de terceros; revisión de marca sigue como punto S6.
