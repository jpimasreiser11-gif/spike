# I2: Instaladores nativos y evidencia de arranque

## Resumen

Entrega apilada sobre I1 (`03f36e533a371085df78a00e78d82a316daee475`), sin integrar ni dar I1 por aceptado.
Añade el flujo de GitHub, envoltorios DMG/Inno/AppImage y autoprueba explícita de la aplicación instalada con pesos
aleatorios diminutos. Se generan hashes únicamente después de verificar evidencia de las tres plataformas y el mismo
commit. Los borradores son privados; no se publica, crea etiqueta, configura cobros ni descarga un modelo real.
Los cambios de LAUNCH1 y su galería quedan conservados en su propia rama y no forman parte de esta entrega.

## Decisiones

Una rama encima de I1 permite revisar solo este incremento. I1 sigue pendiente de revisión; Claude debe integrar
COMPAT1 (#16) antes de la validación conjunta, por sus correcciones previas de Windows. No se cambian el tablero,
STATUS ni CHANGELOG; las propuestas están al final. Se mantienen exclusivamente tags/dispatch como pide la tarea: el workflow existente de instaladores
evita el coste de compilaciones nativas en cada PR. No se activan nuevos disparadores de pago. Cada plataforma compila, instala/extrae y lanza el artefacto final, después se comprueba
la API, los archivos estáticos, catálogo, skills, cuatro tokens de inferencia local y el cierre del motor.

Se usan los binarios CPU de llama.cpp y los pines de I1. PyInstaller/gguf/pywebview se instalan solo en runners;
ninguna dependencia se añade al motor ni se instala en el Mac. Linux abre el navegador para evitar imponer un stack
GUI; Mac/Windows incluyen pywebview con su fallback existente. El asistente sigue necesitando el clic del usuario.

AppImage utiliza appimagetool 1.9.1 y un runtime fijado por ID de asset y hash, sin descarga implícita de otro runtime.
El código es original. Las licencias nativas se incluyen; L2 sigue debiendo revisar las obligaciones de las bibliotecas
embebidas y el resto del bundle. No se afirma que la revisión legal ni la seguridad de distribución estén terminadas.
No se cambian orquestador, permisos, datos de entrenamiento, criterios de medicina ni trabajo de Gemini.
