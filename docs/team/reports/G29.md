# G29: Garantía de que SPIKE no sale a internet sin permiso

## Resumen
Se ha creado la suite `tests/test_no_network_g29.py` que arranca la aplicación real (`create_app(state)`) con `ScriptedProvider` y `app.state.launcher_enabled = True`, intercepta mediante `monkeypatch` cualquier intento de resolución DNS o conexión de red que no vaya a `127.0.0.1` / `::1` / `localhost` (`socket.socket.connect`, `socket.socket.connect_ex`, `socket.create_connection` y `socket.getaddrinfo`) y recorre todos los flujos principales de la API:
- Estado general y asistente de primer arranque sin descargar (`GET /api/health`, `GET /api/system`, `GET /api/setup`).
- Especialistas, proveedores y skills (`GET /api/specialists`, `GET /api/providers`, `GET /api/skills`, `GET /api/skills/{name}`, `PUT /api/skills/{name}`).
- Ajustes, motor local, registro de llamadas/gasto, evolución y sistemas de diseño (`GET /api/settings`, `PUT /api/settings`, `GET /api/runtime`, `GET /api/calls`, `GET /api/usage`, `GET /api/evolution`, `GET /api/design-systems`, `GET /api/design-systems/spike`).
- Conectores MCP sin configurar o desactivados y reglas de dominios del navegador (`GET /api/connectors`, `POST /api/connectors` desactivado, `GET /api/browser/domains`, `GET /api/browser/scripts`).
- Proyectos y archivos del espacio de trabajo (`POST /api/projects`, `GET /api/projects`, `GET /api/projects/{pid}`, `PUT /api/projects/{pid}/files/notes.md`, `GET /api/projects/{pid}/files/notes.md`, `GET /api/projects/{pid}/export`, `GET /api/workspace/files`).
- Memoria neuronal, carpetas, glosario, tutor y grafo (`POST /api/memory`, `GET /api/memory`, `GET /api/memory-status`, `GET /api/memory-export`, `GET /api/memory-folders`, `POST /api/glossary`, `GET /api/glossary`, `GET /api/tutor`, `GET /api/memory-graph`).
- Chat SSE, conversaciones, pruebas (`proof`), búsqueda en el historial y API local compatible con OpenAI (`POST /api/chat`, `GET /api/conversations`, `GET /api/conversations/{cid}`, `GET /api/conversations/{cid}/proof`, `POST /api/history/search`, `GET /v1/models`, `POST /v1/chat/completions`).
- Workflows, plantillas de Creator y cuenta simulada de Finance (`GET /api/workflows`, `GET /api/creator/templates`, `GET /api/finance`, `GET /api/finance/paper`, `POST /api/finance/paper/reset`).

Resultado: **0 intentos de conexión externa o resolución DNS** en todos los flujos locales. No se encontró ninguna salida sin permiso en el núcleo. No medido con pesos reales.

## Archivos tocados
- `tests/test_no_network_g29.py` — Guardia de sockets (`socket.socket.connect`, `socket.socket.connect_ex`, `socket.create_connection`, `socket.getaddrinfo`) y pruebas de extremo a extremo de todos los flujos principales de la API sin red externa.
- `docs/team/reports/G29.md` — Este informe.

## Criterios de aceptación
- [x] Test que arranca la app con el proveedor guionizado, bloquea cualquier conexión que no sea a `127.0.0.1`/`::1` y recorre chat, proyectos, memoria, ajustes, especialistas, skills, conectores sin configurar y estado del asistente de primer arranque (sin descargar).
- [x] Falla inmediatamente si cualquier flujo intenta salir a internet (comprobado en `test_socket_guard_blocks_external_connections_and_allows_loopback` y `test_opt_in_external_features_are_caught_by_socket_guard_when_invoked`).
- [x] Inventario documentado de rutas que salen a internet solo cuando el usuario lo pide y cómo se comprobaron.

## Decisiones
- **Bloqueo tanto en capa de socket (`connect`, `connect_ex`, `create_connection`) como en resolución DNS (`socket.getaddrinfo`)**: interceptar también `socket.getaddrinfo` para nombres que no sean `127.0.0.1`/`::1`/`localhost` garantiza que ni siquiera se filtre una consulta DNS antes de abrir el socket TCP (como ocurre en `WebFetch._resolve_public`).
