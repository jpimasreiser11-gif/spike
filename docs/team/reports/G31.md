# G31: Landing page (not published)

## Resumen
`site/` holds a static landing page in English (`site/index.html`) and Spanish (`site/es/index.html`), rendered by `scripts/build_site.py` from `site-src/` templates. Every figure is a `{{key}}` in the template, filled from `site/figures.json`, which the script reads from the records (Medicine summary and receipt, 16 GB x86 and M4 Max benchmarks, specialist catalog, README quick-start commands). `--check` fails when `site/` differs from what the records produce. No scripts, cookies, analytics or third-party requests; fonts and logos are served from `site/assets/`. Nothing is published, no Pages workflow added, README untouched.

## Criterios
- What SPIKE is / works today / measured with record links / install / licenses / not claimed, in both languages: met (`test_both_languages_have_the_same_sections`).
- Figures from a generated JSON, `--check`: met (`test_figures_equal_the_records`, `test_figures_on_both_pages_equal_figures_json`, `test_no_numbers_typed_by_hand_next_to_unit`, `test_generator_check_passes_and_detects_drift`).
- Install commands are the README ones: met (`test_install_commands_are_the_readme_commands`).
- Local links/assets exist; only github.com/jpimasreiser11-gif/spike and huggingface.co allowed; no script/font/css from other hosts: met (`test_links_and_assets_exist_and_no_third_party_hosts`).
- Brand/font files are byte copies from the repo: met (`test_assets_are_the_repo_brand_and_font_files`). Fonts: Inter 400/700 latin (SIL OFL, already in `marketing/video/public/`, licence text shipped), system stack as fallback.
- Accessibility: landmarks, skip link, alt/width/height, heading order, table scope/caption, focus style, reduced motion: met (`test_accessibility_structure`).
- Contrast (WCAG ratios, computed in `test_palette_and_contrast`): ink/cream 14.55, ink/mint 13.38, ink/green 8.16, ink/shadow 6.13. Greens are never text on cream (green/cream 1.78, shadow/cream 2.37); the test asserts that and that CSS uses only the five palette hexes.
- 375 px without horizontal scroll: met in a real browser (`web/e2e/site-g31.mjs`: scrollWidth 375 = clientWidth, no external requests, no 4xx, both languages, also at 1280). Tables scroll inside their own focusable wrapper.
- Not-claimed section: Finance and the other 12 specialists not accepted; Medicine not published, English benchmarks only; speed on two machines only; no comparison with other apps; real-user routing not measured; installers unpublished and unsigned.

## Decisiones
- "Two commands" are the README install line and `spike serve --open`; `spike models pull qwen3.5-4b` is shown separately as a one-time step (README lists it as another step), and the clone is a stated prerequisite. The README gives `<repository-url>`, so no clone command is invented.
- General-knowledge base/adapter accuracies are not shown (0.6375 rounds ambiguously, see G30); only the paired delta, as in the record.
- Router accuracy (0.89) is not on the page: its source is a STATUS row, not a JSON record.
- llama.cpp is plain text, not a link, because only the project repo and huggingface.co may be linked.
- Hand-written `site/assets/site.css`; everything else in `site/` is generated.
