## 5. Decisiones y avisos

- `npm install` normal falla con `Cannot read properties of null (reading 'edgesOut')` (bug de arborist 10.9.4 al resolver los peers de vitest 5, incluso con jsdom 30 o vitest 4.1.12). El lock se generó con `npm install -E -D vitest@5.0.5 --legacy-peer-deps` sobre un árbol ya instalado con vite 8. Comprobado: `rm -rf node_modules && npm ci` (sin flags) funciona y deja `npm audit` en 0, que es lo que ejecuta CI. Quien cambie dependencias en el futuro puede toparse con el mismo bug de npm y necesitar `--legacy-peer-deps`.
- `npm audit` en 0 cubre también las advertencias de esbuild (la dev server de vite 8 ya no usa esbuild como dependencia directa).
- Dev server: vite 8 sigue sin ser para exponer fuera de localhost; sin cambios en proxy.
