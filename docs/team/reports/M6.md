## Decisiones

QASC para ciencia escolar; CommonsenseQA para razonamiento común; BANKING77 para intenciones de soporte bancario;
URL históricas para clasificación defensiva; BillSum para título a partir de resumen humano. Son recortes medibles,
no una afirmación de dominio completo. Las fichas públicas se consultaron el 30 de octubre; las fuentes siguen
**unverified**. Los corpus, pesos y modelos no se han descargado. Referencias, límites, candidatos descartados,
budgets y reproducción: `training/M6-DATA.md`.

Se conserva la receta M5 con 768 tokens y replay humano. No se generan respuestas para entrenar con Claude/GPT/Gemini/
Llama ni se altera la lista de licencias permitidas. Los targets son anotaciones/títulos humanos originales; las filas
de tests son fixtures locales, no se introducen en entrenamiento. URLs se tratan como texto y nunca se visitan.

El evaluador exacto ignoraba `primary.min_win_rate` y podía devolver éxito si pasaba solamente general. El test nuevo
falló antes de la corrección; ahora pide usar el evaluador pareado. Esto protege también la receta ya existente de
marketing sin cambiar sus criterios. La aceptación de escritura sigue el patrón de marketing (60 %, p <= .05,
caída general <= 1.5); selección y aceptación utilizan archivos distintos exportados de la fuente reservada.
