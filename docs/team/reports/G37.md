# G37: HTTP API reference

Branch `worktree-agent-a41ed044b01b8c032`, merged with main `bc22b77` before the final commit (the merge brought G39's `/api/samples` routes; `--check` caught them as stale until regenerated). G38 was dropped from this
branch (main already has it); this branch only adds G37, following the `scripts/cli_reference.py` pattern.

## Summary

- `scripts/api_reference.py` (no new dependencies) builds the app with `create_app(AppState(home=<temp dir>))`, reads
  `app.openapi()` and writes `docs/api/`:
  - `docs/api/README.md`: bilingual landing page.
  - `docs/api/{en,es}/README.md`: base URL, access rules (Host/Origin check, `SPIKE_API_TOKEN` for `/v1` and `/mcp`),
    a common-errors table (400/401/403/404/405/409/413/422/500/502), the area index and the limits of the reference.
  - `docs/api/{en,es}/<area>.md`: one page per area, 50 per language (`/api/<segment>` grouped by the part before the
    first dash, `v1.md`, `mcp.md`). 235 routes in total (90 GET, 105 POST, 13 PUT, 7 PATCH, 20 DELETE), counted with
    `grep -h "^### \`" docs/api/en/*.md | wc -l`.
- For each route: method and path, the docstring (if it has one), the handler file and function, a parameters table
  (name, in, type, required, default), a body table (dotted fields for nested objects, type, required, default,
  description), the success code and type, an errors table, and a `curl` example against `http://127.0.0.1:8740`.
- Port: the spec says 8741, but the real default of `spike serve --port` is **8740**. The script reads it from the CLI
  parser, so the pages follow it if it changes.
- Errors: FastAPI's declared responses (422) plus a static AST scan of the handler and of the `spike.server` helpers it
  calls by name, for `HTTPException(...)`, `ApiError(...)` and `JSONResponse/Response(status_code>=400)`. Messages are
  copied from the code; f-string parts are shown as `{…}`, except upper-case module constants (`{TOKEN_ENV}` shows as
  `SPIKE_API_TOKEN`). 413 appears on 9 pages (`grep -l "| \`413\` |" docs/api/en/*.md | wc -l`).
- `/v1/chat/completions` reads its JSON itself and `/mcp` is outside the OpenAPI schema (`include_in_schema=False`):
  their body fields are a small hand-written table in the script (from `parse_completion` and `SpikeMcp.handle`); their
  routes, handlers and error codes still come from the app and the scan. Handlers that read a raw body without a schema
  (`read_body`, `spool`, `request.json()`) get a `--data-binary @path/to/file` or JSON `curl` example.
- Deterministic: routes sorted by path and method, areas sorted, error messages sorted, no timestamps, no version.
- `--check` exits 1 and names each stale, missing or extra page (`en/projects.md`, …); `--out DIR` writes or checks
  another folder (used by the tests). CI: `python scripts/api_reference.py --check` added right after the
  `cli_reference.py --check` line in `.github/workflows/ci.yml`.

## Decisions

- One page per area instead of one huge file: about 6,500 lines per language in total (`wc -l docs/api/en/*.md`),
  584 KB for `docs/api` (`du -sh docs/api`).
- Labels and the intro are translated; docstrings and error messages stay as they are in the code (English), and the
  Spanish index says so.
- `<name>` in messages and descriptions is escaped outside code spans, so GitHub does not hide it as an HTML tag.
- Placeholders in `curl` use `<name>` (`<pid>`), not `{pid}`, because curl expands braces.

## Not done / uncertain

- The error scan is static: codes raised deeper than the helpers a handler calls by name, or with a computed status
  (`HTTPException(exc.status_code, …)`), are not listed; a shared helper can list a code one of its routes never
  reaches. The pages say so.
- Many routes return untyped dicts, so their response is just `object`; response bodies are not documented in detail.
- Only checked on Python 3.13 here. The CI matrix runs other versions and operating systems; if a FastAPI/Pydantic
  version produced a different schema there, the check would fail on that runner (not measured).
- No link from the root `README.md` to `docs/api/` (kept the change small); proposed below.
