Small specialist models, built to run on an ordinary 16 GB computer.

One small base model, an orchestrator that picks the specialist, and your own computer first. External API models work with the same instructions when you choose them.

Early, and honest about it. One specialist, Medicine, has passed its acceptance test; it is not published yet. The rest are not accepted yet. Every number below comes from a record you can open.

Install it

What SPIKE is

SPIKE is a local-first app: a server on your computer, a web interface, and the llama.cpp engine. It shares one base model, Qwen3.5-4B, among {{specialists_count}} specialists (Core and domain specialists such as Finance, Medicine, Law and Code). Each domain specialist is meant to add a small trained adapter, so switching specialist costs no model reload.

An orchestrator sends clear requests to the right specialist with a zero-cost lexical router. Only ambiguous or multi-domain requests get a model-written plan. The app also runs on external providers you allow, with paid ones blocked until you enable them.

What works today

  • The app and the engine: web interface, orchestrator, provider layer and local llama.cpp runtime are built and tested.
  • Medicine: its adapter passed the acceptance gate on {{med_date}} (details under Measured). It is not published yet.
  • The other specialists: they run as prompt profiles on the base model and the app marks them as beta.
  • Tools with permissions: calculator, workspace files, sandboxed Python and web fetch, each set to allow, ask or deny.
  • Memory, projects, documents: everything is stored locally and can be edited; Word, Excel, PowerPoint and PDF files are written to your workspace.
  • Works with your tools: an OpenAI-compatible endpoint and an MCP server let other agents and SDKs use SPIKE.
  • Installers: command-line installation works today. Desktop installers exist as candidates and are not published or code-signed yet.

The full list with the evidence for each item is in docs/STATUS.md.

Install in two commands

You need Python 3.11 or newer, llama.cpp (llama-server), npm to build the web interface, 16 GB of RAM recommended and about 3 GB of disk for the model. Start from a clone of the repository, inside its folder:

{{cmd_install}}
{{cmd_run}}

The first command builds the web app and installs SPIKE; the second starts it and opens it in your browser. The first time, download the local model once (its license and SHA-256 are checked), or add an external provider in Settings instead:

{{cmd_pull}}

These are the commands from the README quick start. The step-by-step guide, with what each command does, is in the installation guide. There is no hosted version and no sign-up.

What is not claimed

  • Finance and the other {{others_count}} specialists are not accepted yet. {{accepted_count}} of {{specialists_count}} has an accepted adapter. The others run as prompt profiles on the base model, are marked beta, and are not claimed to beat it.
  • Medicine is not published yet. Its result is against its own base model, on English benchmarks. No Spanish medical benchmark is in the records cited here: not measured.
  • Medicine, Finance, Law and Security are not professional advice, and SPIKE is not a medical device.
  • Speed was measured on two machines only. Other computers and other GPU backends: not measured.
  • No comparison with other apps. SPIKE is not claimed to answer better or run faster than Ollama, LM Studio, Open WebUI or Jan; they were not benchmarked.
  • Routing on requests from real users: not measured. External providers were tested against stand-in endpoints, not live services.
  • Desktop installers are not published and are not signed.
