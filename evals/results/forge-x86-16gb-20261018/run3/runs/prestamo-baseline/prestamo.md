# Cálculo del Préstamo

## Datos del Préstamo
- **Monto**: 10.000 €
- **Tasa de interés**: 5 % anual nominal
- **Duración**: 3 años (36 meses)
- **Sistema**: Francés (amortización francesa)

## Fórmula Utilizada
```
C = P × (i/12) × (1 + i/12)^n / ((1 + i/12)^n - 1)
```

Donde:
- **C** = Cuota mensual
- **P** = Principal (10.000 €)
- **i** = Tasa de interés anual (0.05)
- **n** = Número de pagos (36 meses)

## Cálculo Detallado
```
C = 10.000 × (0.05/12) × (1 + 0.05/12)^36 / ((1 + 0.05/12)^36 - 1)
C = 10.000 × 0.0041667 × 1.19668 / 0.19668
C = 299,71 €
```

## Resultado Final
**Cuota mensual: 299,71 €**

---
*Calculado con el método del sistema francés de amortización.*
