# Code of conduct

SPIKE adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, critique ideas and code rather than people, and keep discussions
welcoming to newcomers. Harassment and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainers through the contact listed on the repository
profile. Maintainers will review every report and may remove content or contributors that break these rules.
