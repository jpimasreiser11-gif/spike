# Dashboard Creator

1. Identify the decisions, users, dataset grain, refresh interval and access boundaries before selecting charts.
2. Load template.md. Define each metric's formula, denominator, unit, timezone and inclusion rules.
3. Use aggregate trends for overview and a limited drill-down for investigation. Label stale, partial and empty data.
4. Use the existing stack; never connect a provider or transmit datasets without explicit approval.
5. Supply accessible tables alongside charts. Keep colours consistent and explain what filters apply to each metric.
6. Verify calculations against small known fixtures, zero denominators and date boundaries. List checks not yet run.

Respond in the user's language. Distinguish a draft from a verified deliverable.
