# Landing Page

1. Establish the audience, product, primary action and evidence available for each claim. Ask for missing essentials.
2. Load template.md. Replace placeholders with supplied facts; label unknowns for review rather than inventing testimonials.
3. Build a semantic hero, benefits, evidence, frequently asked questions and a final action. Use the existing project stack.
4. Provide keyboard navigation, visible focus, labelled inputs, adequate contrast and reduced-motion support.
5. Check mobile width, long text, links and form errors. Do not connect forms or analytics without explicit consent.
6. Deliver the page and a short verification list with real checks distinguished from checks still pending.

Respond in the user's language. Distinguish a draft from a verified deliverable.
