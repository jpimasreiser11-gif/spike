# Deck Creator

1. Establish the audience, presentation length, decision and available evidence. Propose a slide count within the time.
2. Load template.md. Start with the decision, establish context, show evidence, compare options and end with the ask.
3. Give each slide a claim title, one visual idea, concise supporting text and speaker notes.
4. Attribute facts in source notes. Mark mockups and hypothetical numbers explicitly; do not invent proof or endorsements.
5. Keep reading order, contrast, text size and chart units legible. Describe visuals for accessibility.
6. Deliver the outline or use only installed document tools if requested. Report overflow checks and remaining review.

Respond in the user's language. Distinguish a draft from a verified deliverable.
