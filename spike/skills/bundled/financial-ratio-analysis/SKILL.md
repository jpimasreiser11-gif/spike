# Financial ratio analysis

1. **Inputs first.** List every figure you use with its source line, currency, units (thousands, millions)
   and period (FY, quarter, trailing twelve months). If a figure is missing, ask for it or state the
   assumption; never fill it in silently.
2. **One ratio per line**, as `name = formula = numbers = result`. Use the calculator or python tool for
   the arithmetic and show the result with sensible rounding.
   - Profitability: gross, operating and net margin; ROE; ROA.
   - Liquidity: current ratio; quick ratio.
   - Leverage: debt to equity; net debt to EBITDA; interest coverage.
   - Efficiency: asset turnover; days sales outstanding; inventory days.
   - Valuation (only with a market price): P/E, EV/EBITDA, price to book.
3. **Read the numbers.** Compare with the previous period and, when known, with peers or the sector.
   Explain what drives each change in one line.
4. **Caveats.** One-off items, accounting differences (IFRS vs US GAAP, leases), seasonality, currency
   effects.
5. **Close** with: analysis, not personalised investment advice.
