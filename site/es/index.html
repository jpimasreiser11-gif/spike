Modelos especialistas pequeños, hechos para funcionar en un ordenador normal de 16 GB.

Un modelo base pequeño, un orquestador que elige al especialista y tu propio ordenador primero. Los modelos de API externos funcionan con las mismas instrucciones cuando tú los eliges.

Proyecto temprano y claro sobre ello. Un especialista, Medicina, ha superado su prueba de aceptación; todavía no está publicado. Los demás aún no están aceptados. Cada número de abajo viene de un registro que puedes abrir.

Instalar

Qué es SPIKE

SPIKE es una aplicación local primero: un servidor en tu ordenador, una interfaz web y el motor llama.cpp. Comparte un único modelo base, Qwen3.5-4B, entre 13 especialistas (Core y los especialistas de dominio, como Finanzas, Medicina, Derecho y Código). Cada especialista de dominio está pensado para añadir un adaptador pequeño entrenado, así que cambiar de especialista no obliga a recargar el modelo.

Un orquestador envía las peticiones claras al especialista adecuado con un enrutador léxico de coste cero. Solo las peticiones ambiguas o de varios dominios reciben un plan escrito por el modelo. La aplicación también funciona con los proveedores externos que permitas; los de pago siguen bloqueados hasta que los actives.

Qué funciona hoy

  • La aplicación y el motor: la interfaz web, el orquestador, la capa de proveedores y el entorno local con llama.cpp están construidos y probados.
  • Medicina: su adaptador superó el criterio de aceptación el 2026-11-05 (detalles en Medido). Todavía no está publicado.
  • Los demás especialistas: funcionan como perfiles de instrucciones sobre el modelo base y la aplicación los marca como beta.
  • Herramientas con permisos: calculadora, archivos del espacio de trabajo, Python en entorno aislado y descarga web, cada una en permitir, preguntar o denegar.
  • Memoria, proyectos, documentos: todo se guarda en local y se puede editar; los archivos Word, Excel, PowerPoint y PDF se escriben en tu espacio de trabajo.
  • Compatible con tus herramientas: un endpoint compatible con OpenAI y un servidor MCP permiten que otros agentes y SDK usen SPIKE.
  • Instaladores: la instalación por línea de comandos funciona hoy. Los instaladores de escritorio existen como candidatos y aún no están publicados ni firmados.

La lista completa, con la evidencia de cada punto, está en docs/STATUS.md (en inglés).

Especialista de Medicina: aceptado

Con 2,318 preguntas médicas emparejadas en inglés, la precisión pasó de 31.9 % con el modelo base solo a 67.0 % con el adaptador de Medicina. El archivo del adaptador pesa 42,485,024 bytes. Los criterios de aceptación se escribieron antes de entrenar.

Instalar en dos comandos

Necesitas Python 3.11 o superior, llama.cpp (llama-server), npm para construir la interfaz web, 16 GB de RAM recomendados y unos 3 GB de disco para el modelo. Empieza desde un clon de el repositorio, dentro de su carpeta:

(cd web && npm ci && npm run build) && pipx install ".[docs,finance,data,motion]"
spike serve --open

El primer comando construye la aplicación web e instala SPIKE; el segundo lo arranca y lo abre en el navegador. La primera vez, descarga el modelo local una sola vez (se comprueban su licencia y su SHA-256), o añade un proveedor externo en Ajustes:

spike models pull qwen3.5-4b

Son los comandos del inicio rápido del README. La guía paso a paso, con lo que hace cada comando, está en la guía de instalación. No hay versión alojada ni registro de usuarios.

Lo que no se afirma

  • Finanzas y los otros 12 especialistas aún no están aceptados. 1 de 13 tiene un adaptador aceptado. Los demás funcionan como perfiles de instrucciones sobre el modelo base, están marcados como beta y no se afirma que lo superen.
  • Medicina: no publicado todavía. Su resultado es frente a su propio modelo base, en benchmarks en inglés. En los registros citados aquí no hay ningún benchmark médico en español: no medido.
  • Medicina, Finanzas, Derecho y Seguridad no son asesoramiento profesional, y SPIKE no es un producto sanitario.
  • La velocidad se midió solo en dos máquinas. Otros ordenadores y otras GPU: no medido.
  • Sin comparación con otras aplicaciones. No se afirma que SPIKE responda mejor ni vaya más rápido que Ollama, LM Studio, Open WebUI o Jan; no se les hizo benchmark.
  • El enrutado con peticiones de usuarios reales: no medido. Los proveedores externos se probaron con servidores de pega, no con servicios reales.
  • Los instaladores de escritorio no están publicados ni firmados.
